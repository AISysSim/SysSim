# Task 5 - Accelerator Integration Tutorial

## Overview

This tutorial provides an example for SysSim to further integrate with a new accelerator, like PLENA. The user only needs to provide the model, batch size, sequence length, and accelerator config. SysSim then traces one training step and reports the estimated wall time and memory.

The example estimates training performance for:

- Model: `Qwen/Qwen3.5-9B`
- Batch size: `4`
- Sequence length: `1024`
- Accelerator: `1 x PLENA`
- DType: `bf16`
- Optimizer memory assumption: `AdamW`

The current PLENA path uses PLENA simulator cycle estimates.

PLENA simulator repo: <https://github.com/AICrossSim/PLENA_Simulator>

## Example Script

Run this script from the SysSim repo root. It builds a text-only Qwen3.5-9B-shaped model on the PyTorch `meta` device, so it does not allocate real 9B model weights. The script uses the public 9B parameter count for model-state memory estimation.

```python
import time

import torch
from transformers import AutoModelForCausalLM, Qwen3Config

from syssim import PLENAConfig, estimate_training_performance


# ---------------------------------------------------------------------------
# Global config users should edit
# ---------------------------------------------------------------------------
MODEL_NAME = "Qwen/Qwen3.5-9B"
BATCH_SIZE = 4
SEQ_LEN = 1024
DTYPE = "bf16"
OPTIMIZER = "adamw"
NUM_ACCELERATORS = 1
PLENA_FREQUENCY_HZ = 1.0e9

# Public model size used for memory accounting. The runnable local model below
# uses the Qwen3 text architecture with Qwen3.5-9B text dimensions so the
# example does not need remote model code or model weights.
PARAMETER_COUNT = 9_000_000_000

# Qwen3.5-9B text dimensions from the Hugging Face config/model card.
QWEN35_TEXT_CONFIG = dict(
    vocab_size=248320,
    hidden_size=4096,
    intermediate_size=12288,
    num_hidden_layers=32,
    num_attention_heads=16,
    num_key_value_heads=4,
    head_dim=256,
    max_position_embeddings=262144,
    hidden_act="silu",
    rms_norm_eps=1e-6,
    tie_word_embeddings=False,
)


# ---------------------------------------------------------------------------
# Build model and accelerator config
# ---------------------------------------------------------------------------
model_config = Qwen3Config(**QWEN35_TEXT_CONFIG)

with torch.device("meta"):
    model = AutoModelForCausalLM.from_config(
        model_config,
        dtype=torch.bfloat16,
    )
model.train()

plena_config = PLENAConfig.from_plena_submodule(
    frequency_hz=PLENA_FREQUENCY_HZ,
)

# Or specify paths explicitly:
# plena_config = PLENAConfig(
#     settings_path="path/to/plena_settings.toml",
#     isa_lib_path="path/to/customISA_lib.json",
#     frequency_hz=1e9,  # 1 GHz default
# )


# ---------------------------------------------------------------------------
# Run one training-step estimate
# ---------------------------------------------------------------------------
start = time.time()
result = estimate_training_performance(
    model=model,
    accelerator="plena",
    accelerator_config=plena_config,
    batch_size=BATCH_SIZE,
    seq_len=SEQ_LEN,
    dtype=DTYPE,
    optimizer=OPTIMIZER,
    num_parameters_override=PARAMETER_COUNT,
)
host_elapsed_s = time.time() - start


# ---------------------------------------------------------------------------
# Print final report
# ---------------------------------------------------------------------------
print("SysSim training estimate")
print("========================")
print(f"Model              : {MODEL_NAME}")
print(f"Accelerator        : {NUM_ACCELERATORS} x PLENA")
print(f"Batch size         : {BATCH_SIZE}")
print(f"Sequence length    : {SEQ_LEN}")
print(f"DType              : {DTYPE}")
print(f"Optimizer          : {OPTIMIZER}")
print(f"Host run time      : {host_elapsed_s:.2f} s")
print()

print("Wall time")
print("---------")
print(f"Training step      : {result.wall_time_ms:.3f} ms")
print(f"Operators traced   : {len(result.graph)}")
print()

print("Memory")
print("------")
print(result.memory.summary())
print()

if result.warnings:
    print("Warnings")
    print("--------")
    for warning in result.warnings:
        print(f"- {warning}")
```
